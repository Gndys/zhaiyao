## 什么是 ZhaiYao？

ZhaiYao 是面向高频会议团队的 AI 摘要平台，提供录音转写、AI 总结、行动项分发与知识沉淀的一站式能力，帮助你在几分钟内完成会议复盘。

### 核心流程

1. **导入会议内容**：上传 mp3/mp4 等录音文件，或连接 Zoom、腾讯会议、Google Meet 等实时链接。
2. **自动转写**：基于自研声学模型 + Whisper 实现 30+ 语言识别，支持角色区分与噪声环境。
3. **AI 总结**：应用销售回访、项目周会、投后沟通等模板，输出摘要、亮点、风险和下一步计划。
4. **行动项推送**：识别负责人与截止时间，自动同步到 Slack、飞书、钉钉、Jira、Notion、Confluence 或邮件。

### 平台亮点

- 多终端协作：Web、移动端访问逐字稿，支持多人同步编辑与审批。
- 企业级安全：数据静态加密、传输 TLS、细粒度权限、操作审计。
- 知识库沉淀：归档到内部文档或 API，方便后续搜索与复用。

## 垂直落地场景

- 项目与研发协同：项目周会、Scrum、设计评审实时生成任务清单，提醒阻塞项与里程碑。
- 销售与客户成功：售前沟通、客户回访、实施复盘沉淀需求、承诺、下一步跟进动作。
- 经营与战略复盘：高管例会、经营分析会记录 KPI、决策背景、风险提醒，方便审批与复盘。
- 市场与运营：活动复盘、品牌会议提炼 ROI、竞品洞察及下一轮策略。
- 财务、法务与合规：合规例会、审计沟通输出整改项、责任人、追踪节点，满足审计追溯。
- 行政与人力：绩效、人才盘点会统一沉淀结论、发展动作与敏感信息权限。

## 会议类型与摘要结构

### 典型会议类型关注点

- 战略 / 经营会：突出指标、关键决策、所需资源与风险提示，支持高层快速审批。
- 项目推进 / Scrum：强调行动项、负责人、截止时间、依赖关系与阻塞问题。
- 售前 / 客户沟通：提炼客户痛点、预算或竞品信息、明确承诺与下次触达时间。
- 客户成功 / 交付复盘：关注上线情况、问题单、SLA、满意度与升级路径。
- 产品 / 技术评审：记录方案优缺点、技术风险、资源评估与结论。
- 财务 / 合规会议：梳理政策更新、合规义务、整改计划。
- 市场活动复盘：输出 KPI、ROI、获客线索与调整策略。
- 周会 / 信息同步会：快速同步亮点、问题、跨部门依赖与行动清单。

### 常见摘要模板

- 任务清单型：以 RACI 或负责人 + 截止时间输出，适合项目、执行会议。
- 决策记录型：描述议题背景、备选方案、决策理由与批准人，适合战略、高层会议。
- 分析结论型：结构为数据指标 → 结论 → 建议，适合经营、财务、市场会议。
- 客户洞察型：记录客户角色、需求、痛点、承诺事项、跟进计划，适合售前与客户成功。
- 风险 / 合规型：给出风险级别、整改项、里程碑节点，适合法务、审计会议。
- 知识沉淀型：提炼最佳实践、FAQ、参考链接，方便训练知识库或二次复用。

### 场景模板：需求提炼

- **适用会议**：售前沟通、客户方案评审、实施启动会、需求澄清会等以“理解客户诉求→产出方案” 为目标的会议。
- **输出结构**：
  1. 会议目标与共识：会议时间、目的以及会后达成的统一认识。
  2. 客户核心需求：包含痛点、期望、优先级。
  3. 需求拆解：每个需求的功能规格、技术要求、验收标准、衡量指标、资源依赖。
  4. 项目实施计划：阶段/里程碑、时间节点、关键依赖。
  5. 行动项目：负责人、截止日期、状态。
  6. 后续跟进机制：沟通节奏、渠道、责任角色。
  7. 风险与对策：潜在阻碍以及预案。
- **提示词示例**：

```text
你是一位精通会议总结的专业顾问，特别擅长提炼客户需求并转化为具体实施方案。请帮我将以下会议内容整理成一份专业、结构清晰的会议总结。

会议基本信息：
- 会议日期：[填写日期]
- 会议主题：[填写主题]
- 参会人员：[列出关键参会者及其角色]
- 会议目的：[简述会议目的]

会议讨论内容：
[在此粘贴你的会议记录、笔记或关键讨论点]

请在会议总结中包含以下内容：
1. 会议目标与达成的总体共识
2. 客户核心需求分析（包括痛点、期望和优先级）
3. 每个需求点的具体实施细节，包括：
   - 功能规格和技术要求
   - 明确的验收标准和衡量指标
   - 必要的资源和技术依赖
4. 项目实施计划和关键里程碑
5. 明确的行动项目列表（包含负责人、截止日期和状态）
6. 后续跟进计划和沟通机制
7. 潜在风险和应对策略

请使用专业但不晦涩的语言，采用结构化格式（标题、项目符号、表格等）提高可读性，并确保内容既全面又精确。
```
